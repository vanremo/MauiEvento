# MauiEvento

Aplicativo desenvolvido em .NET MAUI para cadastro e gerenciamento de eventos.

## 🧾 Descrição

O MauiEvento é um aplicativo multiplataforma que permite aos usuários cadastrar eventos informando:

- Tipo de evento (ex: Congresso, Festa, Encontro)
- Data de início e término
- Número de participantes
- Local do evento
- Custo por participante

Após o cadastro, é exibido um resumo com os dados do evento, duração e custo total calculado automaticamente.

## 🎯 Objetivo

Este projeto foi desenvolvido com foco no aprendizado prático da tecnologia .NET MAUI, aplicando conceitos de MVVM (Model-View-ViewModel), data binding, layouts com XAML, navegação entre páginas e manipulação de dados.

## 🚧 Melhorias Futuras

- Validação completa dos campos
- Armazenamento em banco de dados
- Lista de eventos cadastrados
- Compartilhamento ou exportação de eventos
